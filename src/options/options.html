Story Studio Audio Generator — Settings

Local studio (localhost) needs no login or access grant. A remote / Tailscale server (e.g. http://mac-mini.tailXXXX.ts.net:8677) needs both.

"Project folder" posts the audio back so it lands in the episode's real audio folder and rebuilds audio_chapters.json. Paste mode always uses Downloads.

Tokens: {project} {episodeCode} {chapterNum} {chapterLabel} {episodeTitle}
