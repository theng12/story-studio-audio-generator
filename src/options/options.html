Story Studio TTS — Settings

Local studio (localhost) needs no login or access grant. A remote / Tailscale server (e.g. http://mac-mini.tailXXXX.ts.net:8677) needs both.

"Project folder" posts the audio back so it lands in the episode's real audio folder and rebuilds audio_chapters.json. Paste mode always uses Downloads.

Tokens: {project} {episodeCode} {chapterNum} {chapterLabel} {episodeTitle}

Provider API keys

Stored locally on this device (never synced). fish.audio needs no key — it uses your logged-in fish.audio tab.

How to get it: open elevenlabs.io → Settings → API Keys, click Create API Key, copy it, and paste it here. The free plan (10k characters/month) includes API access — it draws from the same quota as the website, so this stays free.
