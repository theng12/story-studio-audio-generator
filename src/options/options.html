Story Studio Audio Generator — Settings

Appearance
Story Studio connection (outside Gateway mode)

Use localhost when Story Studio runs on this computer. For a remote or Tailscale server, grant site access, then sign in.

Sign in is only needed when your remote Story Studio server requires credentials.

Finished audio is saved back to the connected Story Studio project.

Gateway Worker (opt-in)

Off by default. When enabled, the extension polls a Relay Gateway for TTS jobs using a local worker token. Jobs are driven through the existing provider tab pipeline; ambiguous failures hold the job for manual review.

Token and worker ID stay in this browser profile only — never synced, never logged.
